You will have 10 MCQ questions of Level I.

These questions are simple MCQ questions.

    

Example:

Which part of Django handles communication with the database?

A) View 

B) Model / ORM

C) Template

D) Admin

    

Explanation:

B) Model / ORM

The Model defines the database structure, and Django’s ORM translates Python code into SQL queries. It’s the layer that actually communicates with the database to create, read, update, or delete data.    

        

Example:

What is the correct syntax to sort students by most recent join date?

A) Student.objects.order_by("join_date")
B) Student.objects.order_by("-join_date") 
C) Student.objects.sort("join_date")
D) Student.objects.desc("join_date")

   

Explanation:

B) Student.objects.order_by("-join_date")

The minus sign (-) sorts results in descending order, showing the most recent students first. Without it, results are sorted oldest first.

  

You will have 10 MCQ questions of Level II.

These questions are code-based MCQ questions.

     

Example:

You registered the model:

# classroom/admin.py
from django.contrib import admin
from .models import Student
admin.site.register(Student)

However, your model isn’t showing up in the Django Admin panel even though you expected it to. What is the most likely cause?

A) Wrong password
B) Didn’t run collectstatic 
C) Forgot to add 'classroom' to INSTALLED_APPS
D) Missing __str__  on model
     

Explanation:

C) Forgot to add 'classroom'to INSTALLED_APPS

Even if you register your model in admin.py, Django will only load it if the app itself is listed in INSTALLED_APPS inside settings.py

If 'classroom' isn’t there, Django doesn’t know the app exists - so its models (e.g. Student) won’t appear in the Admin panel (/admin/).

Example:

Assume you have a Student model with the fields name, email, and join_date. Write a Django ORM query to retrieve all students from the database, ordered alphabetically by their name.

      

Answer:

Student.objects.order_by("name")

     

Explanation:

The order_by("name") method sorts all Student records in ascending alphabetical order (A → Z) based on the name field.
